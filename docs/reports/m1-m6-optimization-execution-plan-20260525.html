Phase 1

试点稳定化准备

周期：1-2 周

执行任务

  • 完成 M5 前端联调：归档柜、柜位、申请单/蜡块/玻片归档、借阅归还、试剂设备台账和预警查询形成可操作工作站。
  • 完成护士、技师、医生、管理员四类岗位 SOP，覆盖主流程、异常处理、权限缺失和人工兜底。
  • 完成 HIS/EMR/LIS/PACS/收费系统字段映射、请求响应样例、失败码、重试策略和对账规则确认。
  • 验证 /actuator/health、/actuator/prometheus、Prometheus 抓取、Grafana 看板和核心告警。
  • 按 docs/rules/RELEASE.md 完成 staging 验证、灰度发布、回滚演练和值班通知。

验收标准

  • docs/plans/M7试点验收清单.md 的验收前提全部打勾。
  • 未关闭阻断项为 0。
  • 试点角色可独立完成日常操作，不依赖研发手工兜底。
Phase 2

试点运行与核心专业化补齐

周期：2-4 周

执行任务

  • 报告正式化：新增正式报告 PDF 渲染、打印、电子签章或签名留痕、签发后防篡改、重新打印留痕。
  • 质控专业化：补齐技术质控、报告质控、TAT SLA、超时升级、阳性/危急值提醒和质控抽检闭环。
  • 设备真实适配：优先接入标签打印机、玻片打号机、包埋盒打号机、高拍仪和扫码枪，统一走适配层并记录失败补偿。
  • 建立试点问题日清机制，按阻断、高频、一般分级，记录根因、绕行方案、修复版本和复核结论。
  • 强化数据权限与审计：导出审批、敏感字段脱敏、管理员操作审计和科室数据隔离策略。

接口边界

  • 可新增报告 PDF/打印相关接口。
  • 可新增设备适配任务查询接口。
  • 可新增质控录入与 TAT 查询接口。
  • 不得破坏 M1-M6 既有接口兼容性。
Phase 3

专业病理扩展能力

周期：4-8 周

执行任务

  • 冰冻流程：术中申请、冰冻取材、快速报告、石蜡复核、冰石符合率统计。
  • 特检/IHC/分子病理：特检医嘱、计费、执行、结果回传、报告合并、试剂批号追溯。
  • 细胞学/液基细胞学：独立标本类型、制片、筛查、复核、报告模板和统计口径。
  • 归档运营增强：批量归档、柜位盘点、归档标签、对象存储文件上传、借阅逾期提醒。
  • 管理驾驶舱：按科室、医生、技师、病种、设备、试剂、TAT、质控维度输出可复核统计。

验收标准

  • 每个扩展业务域具备主链路自动化测试。
  • 每个扩展业务域具备权限测试、异常测试和统计口径验证。
  • 每个扩展业务域具备可培训、可复盘的操作 SOP。

产品与实施

  • 确认外部系统字段映射、失败码、对账规则和人工兜底流程。
  • 组织护士、技师、医生、管理员四类角色演练。

  • 补齐前端工作站、设备适配层、报告 PDF/签章、质控与 TAT 能力。
  • 把 M1-M6 选择性回归、专项测试和发布回滚演练纳入门禁。
