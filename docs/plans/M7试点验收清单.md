# M7 试点验收清单

## 验收前提

- [ ] `M6` 准入结论已确认，见 [M6准入收口说明.md](./M6准入收口说明.md)
- [ ] `M1-M5` 回归通过
- [ ] `M6ClinicalIntegrationTest`、`M6BillingIntegrationTest`、`M6HistoricalReportIntegrationTest`、`M6StatisticsIntegrationTest`、`M6AuthorizationIntegrationTest`、`M6ObservabilityIntegrationTest` 通过
- [ ] 发布窗口、值班表、通知对象、回滚责任人已明确

## 1. 主链路试点验收

- [ ] 护士可完成送检、接收、标签与追踪主流程
- [ ] 技师可完成取材、脱水、包埋、切片、染色主流程
- [ ] 医生可完成诊断、审核、签发、发布主流程
- [ ] 管理员可完成集成任务查询、收费重试/回执/对账、历史导入与统计查询导出
- [ ] 任一角色不存在阻断性的权限缺失

## 2. M6 三条主链路

- [ ] 临床导入可成功创建申请单并保留外部单号、来源系统
- [ ] 临床导入重复提交可被幂等拦截
- [ ] 收费提交失败后可重试成功或进入人工补偿
- [ ] 收费回执可回写外部流水号和对账状态
- [ ] 历史报告导入支持去重与版本重建
- [ ] 历史报告查询可按来源、病人、病理号、申请单号、外部报告号检索

## 3. 监控与告警

- [ ] `/actuator/health`、`/actuator/prometheus` 已验证可用
- [ ] Prometheus 已成功抓取 `bl-center`
- [ ] `bl-center` Grafana 看板可查看服务、业务、JVM、数据库指标
- [ ] 关键告警已验证可触达：
  - 服务不可用
  - Prometheus 抓取缺失
  - 临床导入失败
  - 收费提交/重试失败
  - 历史导入失败
  - 对账差异或人工补偿积压

## 4. 异常兜底与回滚

- [ ] 导入失败有人工作业路径
- [ ] 收费失败有人工作业路径
- [ ] 历史导入失败有人工作业路径
- [ ] 统计导出异常有缩窗或离线补查路径
- [ ] 已完成一次发布回滚演练
- [ ] 回滚后健康检查、核心链路、监控恢复正常

## 5. 退出标准

- [ ] 试点科室已连续稳定运行
- [ ] 高频问题已形成修复版本与复核结论
- [ ] 未关闭阻断项为 `0`
- [ ] 试点总结、问题台账、后续优化清单已留档
