# M1 收口说明

## 摘要

本次收口在 `bl-center` 内补齐了 M1 剩余的关键闭环项，保持现有接口兼容优先，不引入新的认证流程或前端改造。

## 已闭环项

- 编号规则更新写路径已接入统一操作审计，成功和失败都会写入 `operation_logs`。
- 新增内部登录日志记录能力，支持记录成功或失败登录事件。
- 登录成功时同步刷新 `users.last_login_at`、`users.last_login_ip`、`users.last_login_device`。
- 新增用户登录日志分页查询接口：`GET /api/v1/system-users/{id}/login-logs?page=1&size=20`。
- 新增收费项分页查询接口：`GET /api/v1/medical-order-charge-items/page?page&size&enabled&keyword&orderDictItemId`。
- 新增套餐分页查询接口：`GET /api/v1/medical-order-packages/page?page&size&enabled&keyword&packageType`。

## 兼容策略

- 原有 `/api/v1/medical-order-charge-items`、`/api/v1/medical-order-packages` 保留，继续用于轻量参考查询。
- 原有 `/api/v1/roles`、`/api/v1/menus`、`/api/v1/permissions`、`/api/v1/message-topics`、`/api/v1/stat-categories` 返回结构不变。
- 新增分页查询使用与现有用户管理一致的 `PagedResult<T>` 结构：`items / page / size / total`。

## 本期不纳入

- 统一登录、密码校验、会话管理、SSO、LDAP。
- 独立登录接口或完整认证链路。
- 操作日志对外公开查询接口。
- Swagger/OpenAPI 依赖接入。

## 实施落点

- `system`：补充登录日志记录与查询能力。
- `support`：补充编号规则更新审计闭环。
- `masterdata`：补充收费项和套餐分页查询入口。
- `docs`：补充收口说明与验收清单。
