# M1 验收清单

## RBAC 与系统能力

- 创建用户并分配角色成功。
- 查询角色授权、菜单、权限、消息主题、统计类别成功。
- 查询用户最近登录摘要信息成功。
- 查询用户登录日志分页明细成功。

## 主数据与知识库

- 查询部位字典树成功。
- 查询描写模板详情成功。
- 创建医嘱套餐成功。
- 分页查询医嘱套餐成功，可按 `keyword`、`packageType` 过滤。
- 分页查询收费项目成功，可按 `orderDictItemId`、`enabled`、`keyword` 过滤。
- 更新系统配置项成功。

## 编号与审计

- 查询编号规则成功。
- 更新编号规则成功。
- 编号规则更新成功后，`operation_logs` 中可追溯到 `update_numbering_rule` 成功记录。
- 编号规则更新失败后，`operation_logs` 中可追溯到失败记录。
- 并发生成编号无重复。

## 登录日志

- 记录一次成功登录后，`user_login_logs` 写入成功。
- 成功登录后，用户最近登录时间、IP、设备字段被刷新。
- 记录一次仅带 `loginName` 的失败登录后，`user_login_logs` 写入成功。
- 失败登录不会覆盖用户最近登录摘要字段。

## 回归基线

- `mvn -pl bl-center -am test` 通过。
- 既有申请单创建、观测指标、主数据维护、RBAC 配置测试全部通过。
